# Changelog

All notable changes to Mora are recorded here. Dates use ISO 8601.

## [1.0.0] - 2026-10-06
- First production-readiness milestone: five localized screens, searchable ledger, monthly category limits, weekly insights, and accessible transaction entry.
- Added business-logic, repository, widget, and device integration test coverage with a GitHub Actions quality and Android build workflow.
- Added the French-first Malagasy ariary experience and English language / dark appearance settings.

## [0.2.0] - 2026-09-15
- Added the local budget domain model, transaction categories, monthly envelope calculations, and dashboard chart prototype.
- Added French and English copy inventory for the core budgeting flow.

## [0.1.0] - 2026-08-30
- Created Mora's initial offline budget concept with a balance, income and expense tracking, and an ariary-first interface.
